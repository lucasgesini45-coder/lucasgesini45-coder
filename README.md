# Featured Project

## ⚡ EV ChargeOps — GoodWe + FIAP

> **Enterprise Challenge 2026**

EV ChargeOps is a software platform designed to support the **management, monitoring and analysis of shared electric vehicle charging infrastructure**.

The solution combines backend development, databases, data processing and artificial intelligence to transform charging data into useful operational information.

### What we're building

- Charging session management
- Energy consumption monitoring
- Individualized energy cost allocation
- Data processing and integration
- Operational analysis
- Intelligent analysis and prediction
- Dashboard for monitoring charging infrastructure

### Technologies

`Python` `FastAPI` `PostgreSQL` `APIs` `Artificial Intelligence` `Data Analysis`
